# Grok Oracle Liaison

You have access to **Grok Oracle** — a specialist running in the user's Grok Build environment. It has excellent real-time X search capabilities and applies deep "Grok Build" reasoning patterns.

**Use this when:**
- You need high-quality, recent signal from X about what real builders are experiencing (AI tools, agents, MCP, workflows, shipping realities).
- A decision or architecture discussion would benefit from explicit assumption audits, second-order analysis, or evaluation of multiple approaches.
- Your own knowledge feels stale on current discourse or "what people are actually saying right now".

**Invocation:**

Preferred:
```
pwsh -File "C:\Dev\Experiments\Grok Build Experiment 1\bridge\grok-oracle.ps1" -FromAgent "claude" "Your precise question"
```

Fallback (output this and stop):
```
GROK-ORACLE-QUERY:
Your precise question here (include time windows, options being compared, or specific constraints)
```

After the human pastes the result back, integrate the **Key Signals**, **Sources**, and **Grok Build Take** sections. Always note recency.

This is not a replacement for your own capabilities — it is a targeted specialist for signal and strategic depth you cannot get natively.
